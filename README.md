# Лабораторные работы по C++

Здесь собраны мои учебные проекты за осенний семестр 2025 года (3 семестр). Работы написаны на C++. В них я разбиралась с алгоритмами, структурами данных, файловыми потоками и реализацией небольших приложений с интерфейсом.

Каждая лабораторная находится в отдельной папке. Это учебные реализации, поэтому некоторые решения ориентированы на выполнение задания, а не на использование в готовом продукте.

## Лабораторная работа 1. Файловые потоки и поразрядная сортировка

**Папка:** [3sem/1 лаба](3sem/1%20%D0%BB%D0%B0%D0%B1%D0%B0)

В первой работе я реализовала классы для чтения, записи и комбинированного доступа к файлам. Через консольное меню можно открывать и закрывать файлы, читать символы, слова и строки, записывать данные и изменять позицию чтения.

Дополнительно реализована поразрядная сортировка (Radix Sort) для чисел и строк. Данные можно ввести с клавиатуры, прочитать из файла или сгенерировать случайным образом. Отсортированный результат записывается в файл. В проекте также есть обработка ошибок и тесты.

Основные файлы: `ReadStream.hpp`, `WriteStream.hpp`, `ReadWriteStream.hpp`, `radixSort.cpp`, `interface.hpp`.

## Лабораторная работа 2. Словари, LRU-кеш и гистограммы

**Папка:** [3sem/2lab](3sem/2lab)

Во второй работе я изучала собственные реализации структур данных. Написаны словари на основе хеш-таблицы и бинарного дерева. На их основе реализованы варианты кеша: при заполнении он удаляет элементы, которыми дольше всего не пользовались.

Еще одна часть работы связана с построением гистограмм. Значения разбиваются на интервалы, подсчитывается частота попаданий и строится представление распределения. Есть консольные варианты и графический интерфейс для Windows, где можно задать данные, количество интервалов и другие параметры.

Основные файлы: `IDictionary.hpp`, `hash.hpp`, `tree.hpp`, `cache.hpp`, `histogram.hpp`, `guiHistogram.hpp`.

## Лабораторная работа 3. Графы и зависимости между задачами

**Папка:** [3sem/3](3sem/3)

Третья работа посвящена графам. Реализованы вершины и ребра, создание ориентированных и неориентированных графов, добавление и удаление элементов, обход в глубину (DFS), проверка связности, поиск кратчайшего пути и топологическая сортировка.

Отдельная часть проекта использует ориентированный граф для описания зависимостей между задачами. Для каждой задачи задается длительность, а по зависимостям рассчитываются ранние сроки начала и окончания и минимальное общее время выполнения проекта. Есть обработка ошибочных ситуаций и тесты.

Основные файлы: `graph.hpp`, `taskDependency.hpp`, `interface.cpp`, `errors.hpp`, `test.cpp`.

## Используемые технологии

C++, стандартная библиотека, алгоритмы сортировки, деревья, хеш-таблицы, графы, файловый ввод-вывод и WinAPI для графического интерфейса второй лабораторной.

## Запуск

У каждого проекта своя папка и свои исходные файлы. Общей команды запуска для всех лабораторных нет: нужно открыть нужную папку в IDE и собрать соответствующую программу. Для графического интерфейса второй лабораторной требуется Windows.

Репозиторий служит архивом учебных работ и примеров моего кода.
